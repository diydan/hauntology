How to use it

Colours, sizes, gaps, corners and times are tokens: write them once in design/tokens.json, run pnpm build-tokens. A screen is built from the elements below (ui-… classes) and says only where they go. If a piece is missing, add it to design/elements.css and to this page, using tokens only. Yellow is the main colour, green is rare, red is for warnings.

The page needs <body class="ui-page"> and these three links: tokens.css, fonts.css, elements.css. State is a class set from script: is-on, is-done, is-current, is-active, is-haunting, is-speaking, is-open, is-warn, is-bad, is-blackout, is-locked, is-none.

ui-stack puts blocks 12 px apart (tight 8, loose 16); ui-row lays buttons side by side and wraps. A button that is on is aria-pressed="true" (yellow edge and text, not a yellow block); a button that is off but must stay focusable is aria-disabled="true".
