## Two changes to the runner first (no spend, after your yes)

1. **Order.** The cap cut game C last time. Add `--order C,A,B` (the default stays A, B, C), so a cap that bites cuts the hints, which teach the least.
2. **Fresh ledger.** The ledger refuses a second paid run in the same folder (a damaged or full ledger is refused, never reset). The second run uses `--out .ghost-playthrough-2` and a new local Worker state folder, so the day counter of 60 also starts at zero. The old results stay.

The runner already keeps each rejected reply and its reason (committed in `e1e885e`), so the fallbacks can be explained this time.
