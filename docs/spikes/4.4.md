# Spike 4.4: a third paid play-through, for the hint fix

**Status: approved 2026-11-16 (60 calls, $0.02 cap); results at the end.** The second run (`docs/spikes/4.3.md`) found the model swaps the engine's distance word for its own ("a few steps away", "closer than you think"), so 10 of 24 hints fell back. The fix (`2056d21`) quotes the way and the band word in the hint directive, names the swaps, and refuses a hint that adds a distance of its own. Over the second run's 14 accepted model hints, 6 would now be refused, so the fix only helps if the model obeys the quoted words. This run finds out.

## What is tested

The same three games on the same made-up attic, through the real game on a local Worker with the model (`api/wrangler.playthrough.jsonc`, a separate config; `api/wrangler.jsonc` still has no `AI` binding). Every input is made up or a red-team fixture.

**Order B, A, C:** the hints go first, because they are what this run tests. Game C passed in full last time, so if the cap bites, it cuts C.
