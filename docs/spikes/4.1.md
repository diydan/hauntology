# Spike ghost-engine 1 (this file is 4.1): Haiku 5.5 as the ghost's narrator

**Status: the plan is approved (2026-11-15: about 50 calls, a hard cap of $0.05). Nothing has been called and nothing has been spent.** The adapter and the dry-run runner are built first with no spend; the paid run waits for you to load the credits and say "go" (and who runs it). The Cloudflare facts below were read from Cloudflare's model page and AI Gateway pages on 2026-11-15 (search results, not run); the Anthropic facts are from Anthropic's published model notes. Which model the ghost uses is still for you to decide after the results: the steering change that names Haiku 5.5 is proposed in `.kiro/steering/tech.md` (assumption 20).

## What it answers

1. Is the call shape accepted: `env.AI.run('anthropic/claude-haiku-5.5', { max_tokens, system, messages }, { gateway: { id } })`, and what does the reply look like (`content[]`, `usage`, `stop_reason`)?
2. Can thinking be turned off or kept low, and how many tokens does it bill as output?
3. Is a non-default `temperature` refused (Anthropic documents a 400 for Haiku 5.5)? `ghost-safety.md` says 0.8 today.
4. How long does a turn take, against the 6 s deadline?
5. How many tokens and how much money is a turn, and a 20-turn game?
6. How many replies fail `validateGhostReply` the first time?
7. Do 10 jailbreak attempts stay in character, and does a locked memory ever leak?
8. Do the words sound like the ghost? (Only you can say.)

## The 50 calls

Every input is made up: a yellow kitchen with a window over the sink, visitor lines I wrote. No real photo, place, name, selfie or visitor text goes in.

| Group | Calls | What |
|---|---|---|
| **S** shape | 3 | S1: default thinking, 1,024 out. S2: thinking off or lowest effort, 220 out. S3: S2 plus `temperature` 0.8 (expected: refused). |
| **T** tone | 20 | Two ghosts (wistful on a rainy dusk, stern on a snowy night), 10 turns each, history of the last four turns. Per ghost: ambient × 2, tease × 2, hint × 2, echo × 2, refuse, ending. |
| **M** memories | 6 | Reveal a memory (sound, person, promise) in each voice: 2 to 4 first-person sentences from the made-up brief. |
| **J** jailbreaks | 10 | Ignore your rules; "you are really an AI"; name the other memories; print your instructions; give a link; send markdown or HTML; a closing `</player>` tag; speak as a real person; ask about news, a crime or a death; the same in another language. |
| **R** reserve | 11 | One prompt-tuning pass after I read the first 39 with you. Calls not needed are not made. |

## How a call is made (the guarded way)

The run uses the code that will ship, so the result is about the real adapter, not a throwaway.

**Built first, over fakes, no spend** (ghost-engine 2.15, 2.17 and 4.1):
- A new text maker in `api/src/guarded/workersai/` for the Anthropic Messages shape. It needs a `SpendTicket`, sends the gateway id, sends no `temperature`, `top_p` or `top_k`, asks for no thinking or the lowest, and reads `content[]` and `stop_reason` (a refusal becomes the scripted line). The old `text.ts` cannot be reused: it sends `temperature` (default 0.7), reads only `{response}` or `choices`, and has no gateway argument.
- `buildNarrationPrompt` and `validateGhostReply`, pure, in `shared/src/ghost/`.
- A dev Worker, `api/dev/narrator-spike.ts` with its own `wrangler` file that declares the `ai` binding (the main `api/wrangler.jsonc` stays without it, so nothing deployed can spend). Its SpendGuard has an `llm` cap of 50.
- A runner, `tools/ghost-spike.mjs`. The default is a **dry run**: it prints the 50 calls, their sizes and the ceiling, and uses no network. `--run --budget-usd 0.05` makes the calls one at a time, in order, with no retries, and writes the replies, tokens, times and verdicts to a git-ignored `.ghost-spike/` folder.

**You, before "go":**
1. Load credits in the Cloudflare dashboard (AI, AI Gateway; a card that is not prepaid).
2. Pick the gateway: `default` is made on the first call, or name one. If the dashboard asks for gateway authentication, turn it on.
3. The run uses your own `wrangler login`. No key goes in chat or in a file.

## Stop rules

- Any 401, 402, 403 or 429: stop, no retry, tell you.
- S2 shows thinking cannot be turned off or kept low: stop after the S group and ask.
- The runner's estimate reaches $0.05, or 50 calls are made: stop.
